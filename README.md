# Epic Pen — 판서 프로그램

Windows 10/11용 WPF 판서 프로그램입니다.

## 현재 기능
- 투명한 전체 데스크톱 판서창(모니터 여러 대 포함)과 항상 위에 뜨는 도구막대
- 마우스 통과 모드(Esc), 펜, 형광펜, 지우개(펜 획과 도형 모두)
- 직선, 사각형, 원
- 텍스트 입력, 이동, 크기 조절, 편집 및 삭제
- 색 6가지, 굵기 3단계, 지금 고른 도구·색·굵기 강조 표시
- 그린 순서대로 되돌리기(펜·도형 섞여도), 전체 지우기, 종료

## 텍스트 도구
- 판서창이나 도구막대에 포커스가 있을 때 `T`를 누르거나 도구막대의 T 아이콘을 클릭합니다.
- 화면을 클릭해 입력하고 `Enter`로 확정합니다. 줄바꿈은 `Shift+Enter`입니다.
- 글자를 드래그해 옮기고 선택 테두리의 모서리를 드래그해 글자 크기를 조절합니다.
- 더블클릭으로 수정하고, 선택한 글자는 `Delete`로 지웁니다. `Esc`는 편집 중인 내용을 취소하고 마우스 모드로 돌아갑니다.
- 새 글자는 현재 펜 색상을 사용합니다. 글자를 선택한 상태에서 색상을 고르면 해당 글자에도 적용됩니다.

## 실행
- 개발: .NET 8 SDK 설치 후 `dotnet run --project EpicPen.csproj`
- 배포 파일: GitHub Actions의 `EpicPen-win-x64` 아티팩트(런타임 포함 단일 exe)
- .NET 8이 없고 더 새 런타임(.NET 10 등)만 있는 PC에서도 실행됩니다(`RollForward=Major`).

## 고친 점 (1단계 → 동작판)
- 펜·도형 모드에서 클릭이 아래 창으로 새던 문제: 투명 창의 알파 0 픽셀은 윈도우가 클릭을 통과시키므로, 눈에 안 보이는 알파 1 배경을 깔았습니다.
- 판서창을 누르면 도구막대가 판서창 아래로 가려져 다시 누를 수 없던 문제: 도구막대를 판서창의 소유 창으로 두었습니다.
- 되돌리기가 도형부터 지우던 문제: 펜 획과 도형을 한 기록에 넣어 그린 순서대로 되돌립니다.
- 클릭만 해도 크기 0 도형이 쌓이던 문제, 마우스 캡처를 잃으면 미리보기 도형이 남던 문제.

## 검증
1. 크롬/PPT 위에 펜으로 필기
2. 마우스 모드에서 아래 프로그램 클릭
3. 도형 및 지우개(도형도 지워지는지)
4. 펜·도형을 섞어 그린 뒤 되돌리기 순서, 전체 지우기
5. 듀얼 모니터 위치와 배율

## 남은 일
- 전역 단축키(다른 프로그램을 쓰는 중에 펜 켜기/끄기)
- 모니터마다 배율이 다른 듀얼 모니터: 지금은 판서창 하나가 전체를 덮어서 배율이 다른 쪽 모니터에서 좌표가 어긋날 수 있습니다(모니터별 판서창으로 나눠야 함).
- 돋보기, 스포트라이트, 화면 캡처, 화이트보드
