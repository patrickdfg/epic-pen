# Epic Pen — 1단계 판서 엔진

Windows 10/11용 WPF 판서 프로그램입니다.

## 현재 기능
- 투명한 전체 데스크톱 판서창과 독립 도구막대
- 마우스 통과 모드, 펜, 스트로크 지우개
- 직선, 사각형, 타원
- 색상, 굵기, 되돌리기, 전체 지우기

## 실행
Windows PC에 .NET 8 SDK를 설치한 후 `dotnet run --project EpicPen.csproj`을 실행합니다.

## 검증
1. 크롬/PPT 위에 펜으로 필기
2. 마우스 모드에서 아래 프로그램 클릭
3. 도형 및 지우개
4. 전체 지우기 및 되돌리기
5. 듀얼 모니터 위치와 배율

주의: 현재 되돌리기는 도형을 우선 제거합니다. 펜과 도형의 완전한 시간순 되돌리기는 후속 작업입니다. 전역 단축키, 돋보기, 스포트라이트, 캡처는 아직 미구현입니다.
